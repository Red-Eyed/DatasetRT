# DatasetRT social preview

`social-preview.jpg` is the upload-ready image: 1774 × 887 pixels, opaque JPEG,
under 1 MB. Generated with the built-in imagegen tool and converted to JPEG
without resizing or changing the composition.

Upload it in [repository settings](https://github.com/Red-Eyed/DatasetRT/settings)
under **Social preview → Edit → Upload an image**. Committing the image does not
install it as the repository preview. GitHub recommends 1280 × 640 pixels
(minimum 640 × 320), PNG/JPG/GIF, under 1 MB; see the
[official instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
